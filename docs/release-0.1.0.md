# PokeRNGKit 0.1.0 可用性收口计划

## 目标与基线

本轮修复现有模块的错位、遮挡和同类交互不一致，完成版本更新、构建、部署与发版。
目标版本为 `0.1.0`，实际发布前再同步根包、锁文件与桌面包版本。

- 起始基线：`main`，`da8f8ab`；2026-09-13 开始时工作区干净。
- 项目所有者反馈：目前看来没问题的模块只有第三世代 ID 乱数和第三世代定点乱数。
  两者作为当前稳定参考；此反馈不扩展为所有模式、算法结果或设备的正式验收。
- 固定视觉：Ant Neutral HakuStyle。桌面紧凑 RNG 控件沿用 30px，触控恢复至少 44px。
- 不扩展新的 RNG 模块。现有未接入能力逐项记录，不因模块入口存在而声明完整覆盖。

## 完成条件

- 输入、菜单和操作按钮可见且可操作；侧栏切换、长标签、错误提示与模式切换不造成遮挡。
- 同类标签、控件、筛选操作、状态提示、结果表和浮窗行为遵循共享规则。
- 结果首行贴合表头；滚动区域职责明确；窄屏允许合理重排和页面滚动。
- 核对 390px、768px、1280px 和常用桌面视口，兼顾短视口、缩放、浅深主题与键盘操作。
- 模块专属布局归属功能目录，共享组件不按模块名称分支。
- 每个模块区分实现状态、工程检查、生产回归与所有者验收；未接入能力列入发布限制。
- 发布版本对应明确 commit/tag；Web 和 Windows 产物记录来源、工具链、SHA-256 与许可材料。

## 已核对的发布限制

- 本轮首批工程证据：完整 `verify`、625 项前端测试、69 项原生检查与激活 Emscripten 6.0.6
  后的完整 Web/Wasm 构建通过。Windows 打包通过现成 Electron 目录与进程级直连恢复，
  已生成 96,854,911 bytes 的 x64 EXE，SHA-256 为
  `7B58B1B36C06508D4DD99B22313D20292025D1A0956667FEC1CE3CE00F1A61E2`。
  该包仍使用 0.0.0 元数据，只是 Wild 阶段工程试包，不是 0.1.0 发布产物或桌面运行验收。
- 桌面包仍使用默认 Electron 图标，桌面外壳批次需要接入项目图标。
- 共享 `ThreeDsRngInfoCard.tsx` 中的 Timeline 与 Timeline Leap 仍为显式禁用控件。
  普通帧范围与目标帧附近检索不等同于这些工作流；独立 TinyMT Timeline 工具的状态另行记录。
- `docs/module-inventory.md` 仍列有 Gen IV Voltorb Flip Seed / Board Generator 未实现扩展，
  不在本次现有模块 UI 收口中顺带新增。
- Gen V DS 参数、Initial Seed 与 Entralink 的深审仍待执行，不能以入口存在证明对应分支完整。
- 以上是当前源码和库存能确认的限制，不是全模块审计完成声明；后续逐模块补充。
